# LOJAS SPERB

Criei um aplicativo de catálogo/vitrine online ultra leve e focado em idosos (letras grandes, botões gigantes com ícones claros e fundo limpo). O app deve ler os produtos via API do Loyverse usando um Token de Acesso. Na tela inicial, mostre os produtos em formato de lista simples com foto, nome e preço com final ',90'. O cliente pode clicar em um botão de '+' azul e grande para adicionar itens a uma sacola de compras. No topo da tela, coloque um botão bem visível escrito 'Ver Sacola'. Dentro da sacola, limite as opções apenas para revisar os itens e clicar em um botão gigante verde escrito 'Enviar Pedido pelo WhatsApp'. Ao clicar, o app deve abrir o WhatsApp gerando um texto pronto com a lista do pedido e enviar para o número 51996109657. O código deve ser otimizado para navegadores de tablet, evitando processamento em segundo plano para nunca dar tela branca.

O nome da loja é SPERB
